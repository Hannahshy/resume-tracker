# Security and privacy

## Reporting a vulnerability

Please open a GitHub issue without including personal job-application data, screenshots, contact details, or other sensitive information.

## Local data

The application stores job-application records in a local `data.json` file and binds its HTTP server to `127.0.0.1`. The macOS OCR helper uses Apple's Vision framework locally.

Before sharing logs or reproductions, remove company names, job descriptions, interview notes, URLs, and personally identifying information.
